# 修炼伴侣 · 桌面宠物

C9 考研数学修炼系统的桌面伴侣程序。

## 功能

- 🧘 **悬浮宠物** — 桌面角落的小窗，随时看到修炼进度
- 🧊 **心魔突袭** — 定时弹出错题考你，巩固薄弱环节
- 📊 **进度同步** — 自动从网站同步学习数据
- 🔔 **系统托盘** — 最小化到托盘，不打扰

## 安装运行

```bash
cd desktop-pet
npm install
npm start
```

## 构建安装包

```bash
npm run build
```

会在 `release/` 目录生成安装程序。

## 数据说明

程序启动后会自动加载 https://jingqix60-ctrl.github.io/c9-cultivation/ 来同步你的学习进度。
请确保网站可以正常访问。
