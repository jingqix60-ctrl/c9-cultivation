## 二、遗漏题型分析

### 遗漏1: 星形线绕x轴体积（武忠祥辅导讲义例5）

| 字段 | 内容 |
|------|------|
| 题源 | 武忠祥高等数学辅导讲义 · 第三章 · 例5(星形线) |
| 位置 | 武忠祥高数辅导讲义1.md 行7198-7205 |
| 题目 | 星形线 x=a·cos³t, y=a·sin³t。求：(1)所围面积；(2)周长(仅数一数二)；(3)绕x轴旋转体体积和侧面积(侧面积仅数一数二) |
| 与已有题差异 | 已有摆线(张宇习题10.8, 李永乐例4)，星形线是不同参数曲线，积分技法不同（涉及sin⁷t等高次幂） |
| 数三? | 体积部分是，侧面积/周长不是 |
| 收录建议 | **收录**（仅收(1)面积+(3)体积部分），标注侧面积和弧长部分为数一数二 |

### 遗漏2: 极坐标旋转体（武忠祥辅导讲义例4）

| 字段 | 内容 |
|------|------|
| 题源 | 武忠祥高等数学辅导讲义 · 第三章 · 例4 |
| 位置 | 武忠祥高数辅导讲义1.md 行7184-7205 |
| 题目 | 对数螺线 r=e^θ (0≤θ≤π) 及射线 θ=0 和 θ=π 围成平面图形 D。(1)面积A；(2)绕极轴旋转一周所得旋转体体积 |
| 与已有题差异 | 唯一一道极坐标下旋转体体积题。武忠祥用二重积分法 V=2π∬_D y dσ 处理 |
| 数三? | 是（未标注限制）。极坐标面积在张宇第10讲§1有，旋转体体积§2以直角坐标和参数方程为主。极坐标旋转体是武忠祥独有的扩展。 |
| 收录建议 | **收录**，置于较高阶段（金丹/元婴），标注方法差异 |

### 遗漏3: 容器绕y轴容积（武忠祥基础例6 / 李永乐例6）

| 字段 | 内容 |
|------|------|
| 题源 | 武忠祥高等数学基础篇 · 第六章 · 例6 / 李永乐复习全书 · 例6 |
| 位置 | 武忠祥基础3.md 行824 / 李永乐1.md 行7116-7151 |
| 题目 | 容器内侧由曲线绕y轴旋转而成，曲线由 x²+y²=2y (y≥1/2) 与 x²+y²=1 (y≤1/2) 连接而成。(1)求容积；(2)做功(仅数一数二) |
| 与已有题差异 | 分段曲线+绕y轴+对y积分圆盘法+实际应用背景。与已有题不同：曲线是分段圆弧拼接，需要对y分段积分。 |
| 数三? | 容积部分是，做功部分仅数一数二 |
| 收录建议 | **收录**（仅收(1)容积部分），标注(2)做功为数一数二 |
